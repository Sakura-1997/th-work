# 实操考试厂商菜单拆分设计

## 目标

将厂商主数据和考点厂商配置从同一页面的两个页签拆成独立菜单，统一纳入“实操考试管理”一级分组。

## 菜单结构

```text
实操考试管理
- 实操抽题管理
- 实操厂商信息
- 考点厂商管理
- 实操考题管理
```

## 页面职责

| 菜单 | 职责 | 保留字段 |
| --- | --- | --- |
| 实操厂商信息 | 平台级厂商主数据和接口日志 | 厂商名称、编码、推送/回调地址、鉴权、启停、联系人、接口记录 |
| 考点厂商管理 | 考试点直接维护本考点启用厂商 | 考试点、实操厂商、厂商侧考点/租户标识、启停、备注 |

## 不变项

- 不改变厂商推送、成绩回传、抽题或评分规则。
- 不新增厂商与题目映射、设备资源、设备调度或审核流程。
- 现有新增、编辑和接口记录交互保留在各自独立页面。
