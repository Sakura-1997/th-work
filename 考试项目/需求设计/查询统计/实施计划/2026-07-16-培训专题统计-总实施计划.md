# 培训专题统计总实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不新增前端路由、不删除现有数据总览模块的前提下，为 Vue 2、Vue 3 监管端增加页内培训专题统计组件，并在 `spe-exam-biz` 提供真实统计、归档查看和六工作表导出能力。

**Architecture:** 工作拆为文档原型、后端接口、双前端组件三个可独立验收的子计划。现有 `/dataStatistics/overview/index` 保持唯一前端路由；数据总览和培训专题统计通过页内状态切换。后端以九个 GET 接口和一个 POST 导出接口提供独立专题数据，所有查询由服务端收窄监管区域。

**Tech Stack:** Markdown、HTML、Spring Boot 3.4、Java 17、MyBatis-Plus、MySQL、EasyExcel、JUnit 5、Mockito、Vue 2.7、Vue 3.5、Ant Design Vue、ECharts 6、Node test、Playwright。
