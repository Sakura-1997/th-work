## 2. 背景与目标

考试档案管理模块用于对培训考试业务中形成的培训资料、考试组织实施资料、考生个人档案进行统一归集、查看、归档和导出。合同需求中要求系统能够以“考试计划”为基本归档单元，集中管理每次考试活动的完整材料；同时支持以考生个人为中心形成“一人一档”，并导出标准化电子文件包。

本模块目标如下：

1. 支持考试计划维度的档案归档管理，提供考试计划列表、批量档案归档、档案详情查看能力。
2. 支持按培训档案和考试档案两大板块查看考试计划内资料。
3. 支持进入考试计划后查看计划内考生档案列表，并对单个考生执行归档、取消归档、查看和导出。
4. 支持以考生个人为中心聚合培训过程资料、考试过程资料和证书资料，形成“一人一档”。
5. 支持将考生个人档案导出为标准化电子文件包。

## 3. 范围说明

### 3.1 本期范围

| 功能域 | 说明 |
| --- | --- |
| 考试计划归档列表 | 展示考试计划维度的档案归档台账，支持查询、批量归档、详情查看。 |
| 档案详情查看 | 以弹窗展示考试计划档案详情，区分培训档案汇总、考试档案、考生档案列表。 |
| 培训档案汇总 | 展示课程表、学时证明、考核申请表、学历证明、考勤与打卡记录。 |
| 考试档案 | 展示考试成绩单、考务人员。 |
| 考生档案列表 | 展示计划内考生，并支持批量归档、单人归档、取消归档、查看、导出。 |
| 个人档案查看 | 展示考生“一人一档”，包含课程表、学时证明、考核申请表、考勤记录、考试成绩单、考试签到记录、证书。 |
| 资料查看弹窗 | 对课程表、学时证明、考核申请表、学历证明、考勤与打卡记录、考试成绩单等资料以列表表格方式展示。 |

### 3.2 非本期范围

| 功能 | 说明 |
| --- | --- |
| 考试计划档案包导出 | 当前仅支持考生个人档案包导出，不提供“导出考试计划档案包”。 |
| 主列表行内归档/取消归档 | 考试计划列表不提供单行归档或未归档按钮，仅提供批量档案归档和详情查看。 |
| 主列表归档状态列 | 考试计划列表不展示归档状态列。 |
| 考试机构、考试点查询条件 | 考试计划列表查询区不提供考试机构、考试点筛选。 |

## 4. 用户角色

| 角色 | 使用场景 |
| --- | --- |
| 监管机构业务人员 | 查看考试计划档案完整性，检查培训档案与考试档案资料是否齐全。 |
| 考试中心管理人员 | 对考试计划资料进行集中归档，查看计划内考生个人档案。 |
| 档案管理人员 | 对考生个人档案执行归档、取消归档、导出电子文件包。 |

## 5. 核心流程

1. 用户进入“考试档案管理”页面。
2. 用户通过考试计划名称、考生姓名或身份证号、操作项目、考试类型、归档状态、考试日期进行查询。
3. 系统展示考试计划归档列表。
4. 用户可勾选考试计划后点击“批量档案归档”。
5. 用户点击某个考试计划的“档案详情查看”，进入考试计划档案详情弹窗。
6. 用户在详情弹窗中查看“培训档案汇总”“考试档案”“考生档案列表”。
7. 用户在考生档案列表中点击具体考生的“查看”，进入该考生“一人一档”弹窗。
8. 用户可查看该考生各类档案资料，也可执行归档、取消归档或导出个人档案包。

## 6. 页面需求

### 6.1 考试计划归档列表

#### 6.1.1 查询条件

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 考试计划名称 | 输入框 | 支持按考试计划名称模糊查询。 |
| 考生姓名/身份证号 | 输入框 | 支持定位个人档案相关考试计划。 |
| 操作项目 | 下拉框 | 选项包括全部、高压电工作业、低压电工作业、熔化焊接与热切割作业等。 |
| 考试类型 | 下拉框 | 选项包括全部、理论、实操。 |
| 归档状态 | 下拉框 | 选项包括全部、已归档、未归档，用于筛选归档状态。 |
| 考试日期 | 日期区间 | 支持按考试日期范围查询。 |

查询区不展示“考试机构”和“考试点”筛选条件。

#### 6.1.2 列表字段

| 字段 | 说明 |
| --- | --- |
| 勾选框 | 用于批量档案归档。 |
| 序号 | 当前分页内顺序号。 |
| 考试计划 | 展示考试计划名称，点击可进入档案详情查看。 |
| 操作项目 | 展示作业类别，如高压电工作业、低压电工作业。 |
| 考试类型 | 仅展示理论或实操。 |
| 考试时间 | 展示考试日期和时间。 |
| 考试点名称 | 展示考试点名称。 |
| 考生人数 | 展示该考试计划内考生数量。 |
| 操作 | 提供“档案详情查看”。 |

#### 6.1.3 操作规则

| 操作 | 规则 |
| --- | --- |
| 查询 | 按当前条件刷新考试计划列表。 |
| 重置 | 清空查询条件并恢复默认列表。 |
| 批量档案归档 | 对勾选考试计划执行归档动作，归档单元为考试计划。 |
| 档案详情查看 | 打开考试计划档案详情弹窗。 |

考试计划列表不展示归档状态列，不提供行内“归档”“未归档”按钮。

### 6.2 考试计划档案详情弹窗

档案详情以弹窗展示，不使用抽屉。弹窗顶部展示考试计划基本信息。

#### 6.2.1 基本信息

| 字段 | 说明 |
| --- | --- |
| 考试计划 | 当前查看的考试计划名称。 |
| 考试点名称 | 当前考试计划所属考试点。 |
| 考试时间与地点 | 展示考试时间和具体考场。 |
| 计划内考生 | 展示本考试计划内考生人数。 |

档案详情顶部不展示监考员、考评员、巡考员和审批信息。

#### 6.2.2 培训档案汇总

| 资料 | 操作 | 展示要求 |
| --- | --- | --- |
| 课程表 | 查看 | 弹窗中以课程列表展示班级名称、课程名称、上课时间、授课教师；不展示授课地点；培训日期与上课时间合并为“上课时间”。 |
| 学时证明 | 查看 | 弹窗标题为“学时证明列表”，以考生维度展示考生姓名、身份证号、学时、证明编号、培训机构、学时证明表；学时证明表列提供“查看预览”按钮。 |
| 考核申请表 | 查看 | 复用考试资格审批中的考核申请表口径，展示考生姓名、身份证号、操作项目、申请类型、审批时间、考核申请表；不展示原机构意见和审核结论字段；考核申请表列提供“查看预览”按钮。 |
| 学历证明 | 查看 | 以学生维度列表展示考生姓名、身份证号、学历层次、核验结果、学历证明；不展示原材料名称字段；学历证明列提供“查看预览”按钮。 |
| 考勤与打卡记录 | 查看 | 考勤与打卡记录弹窗提供姓名查询条件。列表展示姓名、身份证号、核验时间、核验方式、现场照片。 |

培训档案汇总不展示覆盖人数、缺失人数、核验状态等统计字段。

#### 6.2.3 考试档案

| 资料 | 操作 | 展示要求 |
| --- | --- | --- |
| 考试成绩单 | 资料预览 | 弹窗中以成绩列表展示考生姓名、准考证号、考试科目、成绩、结果、发布时间。 |
| 考务人员 | 查看 | 点击考试档案列表中的“考务人员”记录打开考务人员列表弹窗，展示姓名、考务人员类型、证件号码、政治面貌、性别、最高学历、移动电话、工作类型、所属考点。 |

考试档案列表不展示考试计划、关键内容、人员/机构、状态等列；资料类型列不再按监考、考评、巡考人员类型拆分。

#### 6.2.4 考生档案列表

| 字段 | 说明 |
| --- | --- |
| 考生姓名 | 展示计划内考生姓名。 |
| 身份证号 | 脱敏展示身份证号。 |
| 操作项目 | 展示考生报名作业项目。 |
| 考试档案 | 展示该考生考试档案完整性。 |
| 考试成绩 | 展示分数和合格结果。 |
| 个人档案状态 | 展示已归档或未归档。 |
| 操作 | 提供归档、取消归档、查看、导出。 |

考生档案列表顶部提供“批量归档”按钮。列表不展示培训档案字段，不展示个人关联内容和状态统计卡片。

### 6.3 个人档案查看弹窗

个人档案以考生为中心展示，标题需明确当前考生、操作项目和“一人一档”。导出按钮需明确导出对象，例如“导出张某某个人档案包”。

#### 6.3.1 基本信息

| 字段 | 说明 |
| --- | --- |
| 考生姓名 | 当前查看的考生姓名。 |
| 身份证号 | 脱敏展示身份证号。 |
| 本次考试计划 | 当前关联考试计划。 |
| 个人档案状态 | 展示该考生个人档案归档与导出状态。 |

#### 6.3.2 个人档案资料

| 资料 | 操作 | 展示要求 |
| --- | --- | --- |
| 课程表 | 查看 | 以列表展示课程名称、上课时间、学时、签到结果、授课教师。 |
| 学时证明 | 查看 | 以列表展示学习日期、课程名称、学习方式、获得学时、记录状态。 |
| 考核申请表 | 查看 | 复用考试资格审批中的考核申请表口径，展示考生姓名、身份证号、操作项目、申请类型、审批时间、考核申请表，并在考核申请表列提供“查看预览”按钮。 |
| 考勤记录 | 查看 | 以列表展示培训日期、签到时间、签退时间、打卡方式、考勤结果。 |
| 考试成绩单 | 查看 | 以列表展示考试科目、考试时间、考试地点、成绩、结果、发布人。 |
| 考试签到记录 | 查看 | 以列表展示签到时间、签到方式、核验项目、核验结果。 |
| 证书 | 查看 | 展示证书类型、证书状态、关联考试。 |

个人档案导出范围仅包含当前考生档案，不包含同一考试计划下其他考生档案。

## 7. 资料查看弹窗要求

| 要求 | 说明 |
| --- | --- |
| 展示方式 | 使用居中弹窗展示，不使用抽屉。 |
| 左侧区域 | 不展示左侧元信息面板。 |
| 内容结构 | 资料正文区域根据资料类型展示表格或文本。 |
| 列表资料 | 课程表、学时证明、考核申请表、学历证明、考勤与打卡记录、考试成绩单、考试签到记录必须以列表表格展示。 |
| 考务人员列表 | 考务人员列表以独立居中弹窗展示，字段为姓名、考务人员类型、证件号码、政治面貌、性别、最高学历、移动电话、工作类型、所属考点。 |
| 关闭 | 点击关闭按钮或遮罩关闭资料弹窗。 |

## 8. 数据与状态规则

| 项目 | 规则 |
| --- | --- |
| 考试计划归档单元 | 档案归档以考试计划为基本单位。 |
| 个人档案归档单元 | 个人档案以考生为基本单位。 |
| 主列表考试类型 | 仅允许理论、实操。 |
| 个人档案状态 | 仅允许已归档、未归档。 |
| 个人导出 | 导出标准化电子文件包，文件包应包含该考生全部培训、考试、证书相关资料。 |

## 9. 权限与审计

| 功能 | 权限要求 | 审计要求 |
| --- | --- | --- |
| 查看考试计划档案 | 具备考试档案查看权限 | 记录查看人、查看时间、考试计划。 |
| 批量档案归档 | 具备档案归档权限 | 记录操作人、操作时间、考试计划、归档结果。 |
| 个人档案归档 | 具备个人档案归档权限 | 记录操作人、操作时间、考生、归档结果。 |
| 取消归档 | 具备取消归档权限 | 记录操作人、操作时间、取消原因。 |
| 导出个人档案包 | 具备档案导出权限 | 记录导出人、导出时间、考生、文件包编号。 |

## 10. 验收标准

| 编号 | 验收项 | 通过标准 |
| --- | --- | --- |
| A01 | 查询条件 | 考试计划列表支持考试计划名称、考生姓名/身份证号、操作项目、考试类型、归档状态、考试日期查询。 |
| A02 | 查询条件移除 | 考试计划列表查询区不展示考试机构和考试点。 |
| A03 | 考试类型 | 查询条件包含理论和实操，主列表考试类型值仅为理论或实操。 |
| A04 | 主列表字段 | 主列表展示考试计划、操作项目、考试类型、考试时间、考试点名称、考生人数、操作等字段。 |
| A05 | 主列表归档状态 | 主列表不展示归档状态列。 |
| A06 | 主列表操作 | 主列表提供批量档案归档和档案详情查看，不提供行内归档/未归档按钮。 |
| A07 | 档案详情 | 档案详情以弹窗展示，包含培训档案汇总、考试档案、考生档案列表三个页签；顶部基本信息不展示监考、考评、巡考人员和审批结果。 |
| A08 | 培训档案汇总 | 培训档案汇总仅展示资料类型和查看操作，不展示覆盖人数、缺失人数、核验状态；课程表、学时证明、考核申请表、学历证明、考勤与打卡记录字段与本 PRD 6.2.2 一致。 |
| A09 | 考试档案 | 考试档案仅展示资料类型和操作，资料类型包含考试成绩单、考务人员，不展示考试计划、关键内容、人员/机构、状态，不单独展示考务人员列表列。 |
| A10 | 考生档案列表 | 考生档案列表提供批量归档，行内提供归档、取消归档、查看、导出。 |
| A11 | 个人档案 | 个人档案包含课程表、学时证明、考核申请表、考勤记录、考试成绩单、考试签到记录、证书。 |
| A12 | 资料弹窗 | 课程表、学时证明、考核申请表、学历证明、考勤与打卡记录、考试成绩单、考试签到记录以表格列表展示；考务人员列表弹窗展示姓名、考务人员类型、证件号码、政治面貌、性别、最高学历、移动电话、工作类型、所属考点。 |
| A13 | 导出范围 | 个人档案导出仅导出当前考生标准化电子文件包。 |
| A14 | 归档单元 | 考试计划归档以考试计划为单位，个人档案归档以考生为单位。 |
