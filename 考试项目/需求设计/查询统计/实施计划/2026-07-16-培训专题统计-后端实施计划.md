# 培训专题统计后端实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `spe-exam-biz` 实现培训专题概览、六专题统计、只读归档和六工作表 Excel 导出接口。

**Architecture:** 新建独立 `trainingstatistics` 契约包、Mapper、Service 和 Controller，复用现有区域收窄与百分比工具，不修改 `spe-exam-api`。Mapper 返回原始计数，Service 负责比率、字典、连续月份、分页和区域权限。导出 Service 使用同一 Mapper 和已规范化的六组条件生成 EasyExcel 多工作表。

**Tech Stack:** Java 17、Spring Boot 3.4、MyBatis-Plus、MySQL、EasyExcel、JUnit 5、Mockito、AssertJ。

`TrainingStatisticsQuerySupport` 必须：校验完整日期、构造左闭右开时间、限制分页、调用现有 `DataStatisticsScopeResolver.resolveAreaId`、把省级编码规范化为 `null`。处罚年份为空时使用传入的当前年。禁止写入租户 ID。

```java
public static void prepare(TrainingStatisticsQuery query, SptUser user, String institutionAreaId) {
    if (query == null) throw new BusinessException("统计查询参数不能为空");
    if (query.getStartDate() == null || query.getEndDate() == null) {
        throw new BusinessException("请选择完整的计划日期范围");
    }
    if (query.getStartDate().isAfter(query.getEndDate())) {
        throw new BusinessException("计划开始日期不能晚于结束日期");
    }
    query.setStartTime(query.getStartDate().atStartOfDay());
    query.setEndTimeExclusive(query.getEndDate().plusDays(1).atStartOfDay());
    query.setCurrent(Math.max(1, query.getCurrent()));
    query.setSize(Math.max(1, Math.min(100, query.getSize())));
    String areaId = DataStatisticsScopeResolver.resolveAreaId(
            query.getAreaId(), user.getId(), user.getUsername(), institutionAreaId);
    query.setAreaId(areaId == null || AreaScopeUtils.isProvinceArea(areaId) ? null : areaId);
}
```
