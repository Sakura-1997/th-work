## 2. 背景与目标

数据总览用于集中展示培训、考试、证书、考务人员和缴费等业务运行数据，辅助监管人员查看授权区域内的业务规模、通过率、人员结构、机构对比和趋势变化。V1.3 在不改变原数据总览内容的基础上，增加培训专题统计，面向监管人员提供培训计划、人员、机构、老师、通过情况和机构处罚六个专题的纵向分析与归档资料查询。

本版本以当前已经开发完成的数据总览页面为展示基线，PRD、HTML 原型、Vue 2 页面和 Vue 3 页面使用相同的模块、标题、字段与交互。页面仍使用 `/dataStatistics/overview/index`，不新增前端路由或左侧菜单。数据总览与培训专题统计均实时查询，不使用生产模拟数据、不缓存、不自动刷新。

页面采用现有监管系统的纵向驾驶舱布局。内容区顶部增加页内一级切换“数据总览 / 培训专题统计”，默认展示“数据总览”，切换时 URL 和左侧菜单保持不变。

“数据总览”完整保留原页面内容，从上到下依次为：

1. 页面顶部公共筛选区。
2. 总览。

4. 考试分析。

“培训专题统计”为同页组件，顶部提供六个专题锚点、“一键导出六个”和“归档资料”入口；六个专题在页面内纵向排列：

1. 培训计划统计。

视觉样式遵循现有系统：深蓝色左侧导航、`#1677ff` 主按钮和数据强调色、浅灰页面背景、白色面板、4px 左右的小圆角、细分隔线和紧凑型统计布局。分区标题左侧不显示 `01`、`02` 等序号。

## 6. 筛选与查询交互

### 6.1 数据总览筛选条件

| 筛选项 | 默认值 | 作用范围 |
| --- | --- | --- |
| 地市 | 全部授权地市 | 全部六个分区 |
| 开始日期 | 当前年度 1 月 1 日 | 全部六个分区 |
| 结束日期 | 当前日期 | 全部六个分区 |

时间范围使用一个开始日期和结束日期组成的日期范围选择器。开始日期不得晚于结束日期。

### 6.2 培训专题筛选条件

前五个常规专题分别维护自己的筛选条件：培训计划关键字、人员分类、地市（即地域）、计划开始日期、计划结束日期。不得出现单位或培训机构筛选。培训计划日期按区间相交口径过滤，默认开始日期为当前年度 1 月 1 日，默认结束日期为当天。

培训机构处罚专题只允许地市、评估年度两个筛选项，默认评估年度为当前年度；不得出现培训计划、人员分类、日期、单位或培训机构筛选。

### 6.3 查询行为

- 页面首次进入时，六个分区使用默认条件并行查询。
- 点击“查询”时，六个分区使用当前公共条件重新实时统计。
- 点击“重置”时恢复默认地市和本年度日期范围，并重新查询。
- 公共条件发生查询或重置时，培训机构明细、考试安排明细和考务人员明细均回到第 1 页。
- 六个分区分别维护加载、错误和请求序号；一个分区失败不影响其他分区展示。
- 快速连续查询时，较早请求的迟到响应不得覆盖最新结果。
- 首次切换到“培训专题统计”时，六个专题使用默认条件并行实时统计；仅进入数据总览时不提前请求专题数据。
- 每个培训专题独立维护筛选值、分页、加载状态、错误状态、请求序号和最后一次成功查询条件；单区失败不影响其他专题，过期响应直接丢弃。
- 每个专题的“查询”只刷新本专题并回到第 1 页；“重置”恢复本专题默认条件、回到第 1 页并重新查询。
- 专题数据不缓存、不自动刷新；再次进入专题视图时保留当前展示，只有用户查询、重置、分页、重试或重新进入页面时才发起请求。

## 7. 公共数据口径

| 口径项 | 规则 |
| --- | --- |
| 删除标识 | 涉及业务表默认过滤 `del_flag = '0'`；没有该字段的表不添加此条件 |
| 监管范围 | 服务端根据当前用户授权区域强制收窄数据范围；地市用户不能通过参数扩大到其他地市 |
| 考试监管口径 | 考试统计按当前监管区域限制，不使用考试点机构 `tr_institution.tenant_id` 作为监管数据过滤条件 |
| 时间边界 | 开始日期包含当天；结束日期包含当天，SQL 使用结束日期次日零点作为排他上界 |
| 人数去重 | 人数优先按业务人员 ID 去重；跨考试实例统计人员时按身份证号等人员唯一标识去重 |
| 有效考试实例 | `instance_status = '1'`、`del_flag = '0'`，且 `exam_result IN ('1','2')` 或 `score IS NOT NULL` |
| 合格考试实例 | 有效考试实例中 `exam_result = '1'` |
| 培训合格 | `tr_trainee_signup.training_qualify_status = '1'`，其他值按业务状态分别计入不合格或待判定 |
| 培训计划日期 | 计划区间与筛选区间相交即纳入，即 `plan_start_date <= filter_end_date` 且 `plan_end_date >= filter_start_date` |
| 启用机构数 | 仅受服务端授权区域和地市筛选影响，不受日期、培训计划关键字、人员分类影响 |
| 区域上卷 | 服务端强制按授权区域收窄，区县数据上卷至所属地市；客户端参数不得扩大数据范围 |
| 机构监管过滤 | 监管统计不按 `tr_institution.tenant_id` 过滤 |
| 处罚来源 | 培训机构违规次数取 `tr_institution_evaluation.violation_count` |
| 比率展示 | 后端返回 0 到 100 的百分数并保留 1 位；分母为 0 时返回 `null`，前端显示 `--` |
| 金额展示 | 当前支付链路金额单位为分，展示万元 = `SUM(amount) / 1,000,000`，保留 2 位 |
| 未归类数据 | 缺少人员分类时显示“未归类”；缺少地市的数据不参与地图着色和地市排名 |

## 8. 字典与分类规则

### 8.1 人员分类

人员分类名称由系统字典 `qualification_root_category` 或 `QualificationRootCategoryEnum` 提供，页面和服务端不得重复维护中文 Map。

| 编码 | 展示名称 |
| --- | --- |
| `01` | 主要负责人 |
| `02` | 安全生产管理人员 |
| `03` | 特种作业人员 |

考试报名和缴费优先从 `exm_exam_signup.exam_codes` 解析，无法获取时回退到 `exm_exam.exam_codes`；证书使用 `tr_certificate.person_type_code`。

### 8.2 考务人员类型

考务人员名称由系统字典 `staff_type` 或 `StaffTypeEnum` 提供。服务端兼容历史编码 `01/02/03` 与当前编码 `1/2/3`，统一映射为监考员、考评员、巡考员。

### 8.3 培训专题字典

培训专题的人员分类、老师专兼职、授课类型、评估等级和评估状态分别使用以下系统枚举，前后端均不得维护中文硬编码 Map：

| 业务字段 | 枚举 |
| --- | --- |
| 人员分类 | `QualificationRootCategoryEnum` |
| 老师专兼职 | `TeacherStaffCategoryEnum` |
| 授课类型 | `TeachingTypeEnum` |
| 评估等级 | `EvaluationGradeEnum` |
| 评估状态 | `EvaluationStatusEnum` |

## 9. 指标来源与计算口径

### 9.1 总览

#### 核心指标

| 指标 | 来源 | 计算方式 |
| --- | --- | --- |
| 培训人数 | `tr_class_trainee`、`tr_class`、`tr_trainee_signup` | 查询期内正式入班人员数，按 `trainee_signup_id` 去重；`tr_class_trainee.status = 1` |
| 考试通过率 | `exm_exam_signup_instance`、`exm_exam_signup`、`exm_exam` | 合格考试实例数 / 有效参考考试实例数 |
| 首次通过率 | 同上 | 初考合格人员数 / 初考参考人员数；初考按 `exam_attempt_type = 0` 判断 |
| 证书有效率 | `tr_certificate` | 查询期内有效证书数 / 查询期内证书总数；有效证书需 `cert_status = '1'` 且当前日期位于证书有效期内 |
| 发证人数 | `tr_certificate` | 查询期内 `cert_status = '1'` 的证书按 `idcard_num` 去重 |

#### 图表与排名

| 组件 | 计算及展示规则 |
| --- | --- |
| 区域监管态势 | 以江西省 11 个地市为基线；支持“考试通过率”和“证书有效率”切换；区县区域上卷为所属地市；无指标值地市保留灰色轮廓并显示 `--` |
| 地市排名 | 当前地图模式对应指标的地市 TOP 5；只显示有有效指标值的地市，不单列区县 |
| 趋势对比 | 按月展示培训人数和考试通过率；查询范围内缺失月份由服务端补零或空值 |
| 机构通过率排行 | 按培训机构统计有效考试实例通过率：合格实例数 / 有效参考实例数，降序展示 TOP 4 |
| 人员分类分布 | 查询期内按报名人员去重，展示三类人员及未归类人员占比 |

### 9.2 培训分析

#### 核心指标

| 指标 | 计算方式 |
| --- | --- |
| 培训人数 | 查询期内正式入班人员数，按 `trainee_signup_id` 去重 |
| 参考人数 | 查询期内存在有效考试结果的人员数，按人员唯一标识去重 |
| 培训合格人数 | 查询期内 `tr_trainee_signup.training_qualify_status = '1'` 的正式入班人员数 |
| 机构考生通过率 | 查询期内全部机构合格考试实例数 / 有效参考考试实例数 |
| 启用培训机构 | 筛选区域内 `tr_institution.status = '0'`、`del_flag = '0'` 的全部启用机构数；不受日期范围影响 |

#### 图表与明细

| 组件 | 展示规则 |
| --- | --- |
| 培训人数趋势 | 按月统计培训人数；没有数据时显示“暂无数据” |
| 重点机构通过率 | 按有效考试实例通过率降序展示 TOP 4 |
| 培训机构考生考试通过率 | 服务端分页；列为培训机构、培训人数、参考人数、实例通过率、首次通过率、最终通过率 |

机构明细中的比率口径：

- 实例通过率 = 合格考试实例数 / 有效参考考试实例数。
- 首次通过率 = 初考合格人员数 / 初考参考人员数。
- 最终通过率 = 至少一次考试合格人员数 / 有考试结果人员数。

### 9.3 考试分析

| 组件 | 来源与展示规则 |
| --- | --- |
| 地市考试人数分布 | `exm_exam.examinee_number` 按考试点区域汇总；图表名称为“地市考试人数分布” |
| 考试类型与人员分类 | 同一横向条形图展示理论考试、实操考试及三类人员的考试人数 |
| 考试安排明细 | 服务端分页；列为考试日期、地市、考试点、考试类型、人员分类、考试人数；按考试日期和主键倒序 |

考试类型 `type = '1'` 展示“理论”，`type = '2'` 展示“实操”，其他值展示“未归类”。

### 9.4 证书分析

#### 核心指标

| 指标 | 计算方式 |
| --- | --- |
| 证书有效率 | 有效证书数 / 查询期内证书总数 |
| 发证人数 | 查询期内 `cert_status = '1'` 的持证人去重数 |
| 有效证书 | 查询期内 `cert_status = '1'` 且当前日期位于有效期内的证书数 |
| 持证人员 | 查询期内按 `idcard_num` 去重的持证人数 |

#### 图表与明细

| 组件 | 展示规则 |
| --- | --- |
| 证书状态 | 环形图展示“有效证书”和“其他证书”，副标题为“有效证书占比” |
| 证书办理量 | 按 `valid_begin_date` 统计，日期为空时使用 `create_time`，按月展示 |
| 持证人员分布 | 不分页；列为人员分类、持证人员、有效证书；不展示发证机关 |

### 9.5 考务人员

| 组件 | 展示规则 |
| --- | --- |
| 人员类别占比 | 仅统计 `status = '0'` 的启用人员，按监考员、考评员、巡考员展示环形图 |
| 人员数量概览 | 与人员类别占比使用同一启用人员数据，横向条形图展示人数 |
| 考务人员明细 | 服务端分页；列为区域、考试点、监考员、考评员、巡考员、数据状态；同一考试点的启用和停用数据按状态分行 |

数据状态在页面显示“正常”或“停用”，并使用系统现有标签样式区分。

### 9.6 缴费分析

#### 金额卡片

金额卡片按接口返回动态渲染，最多显示 6 张：

1. 缴费总额。
2. 缴费金额排名第 1 的地市。
3. 缴费金额排名第 2 的地市。
4. 特种作业人员缴费金额。
5. 安全生产管理人员缴费金额。
6. 主要负责人缴费金额。

接口未返回对应地市或人员分类时，不生成虚假的金额卡片。所有金额单位统一为万元，不展示金额占比。

#### 地市人员分类缴费情况

- 仅统计支付成功订单：`tr_pay_order.order_state = '1'` 或 `third_party_tran_status = '1'`。
- 金额优先取订单明细 `tr_pay_order_detail.amount`，没有明细时取订单 `tr_pay_order.amount`。
- 人员分类通过报名实例和报名信息解析，无法获取时回退到考试安排分类。
- 地市通过考试安排的考试点区域获取。
- 图表按地市展示三类人员金额的堆叠柱，柱顶为该地市缴费合计。
- 没有可归类的地市金额时显示“暂无数据”。

### 9.7 培训计划统计

| 类型 | 名称 | 口径或字段 |

| 指标 | 进行中 | 当前日期位于计划开始、结束日期内且业务状态为进行中的计划数 |
| 指标 | 已完成 | 业务状态为已完成的计划数 |
| 指标 | 拟培训人数 | 符合条件计划的拟培训人数合计 |
| 指标 | 实际参训人数 | 符合条件计划内正式参训人员去重数 |
| 图表 | 状态分布 | 按系统计划状态分组展示计划数 |
| 图表 | 月度计划趋势 | 按计划开始月份展示计划数 |
| 明细 | 一计划一行 | 计划名称、培训机构、人员分类、培训方式、计划日期、拟培训、实际参训、状态 |

培训方式名称读取系统既有字典；培训计划日期使用区间相交规则。明细按计划开始日期、主键倒序。

### 9.8 培训人员统计

| 指标 | 参训人数 | 符合条件计划内正式参训人员去重数 |
| 指标 | 合格 | `training_qualify_status = '1'` 的参训人员数 |
| 指标 | 不合格 | 业务状态明确为不合格的参训人员数 |
| 指标 | 待判定 | 合格状态为空或业务状态为待判定的参训人员数 |
| 指标 | 覆盖计划数 | 至少有一名正式参训人员的计划去重数 |
| 图表 | 人员分类分布 | 按 `QualificationRootCategoryEnum` 分组展示参训人数 |
| 图表 | 参训趋势 | 按计划开始月份展示参训人数 |
| 明细 | 计划 + 人员分类 | 计划名称、人员分类、参训、合格、不合格、待判定、合格率 |

明细合格率 = 合格人数 / 参训人数；人数在每个计划和人员分类组合内按人员业务 ID 去重。

### 9.9 培训机构统计

| 类型 | 名称 | 口径或字段 |

| 指标 | 计划数 | 符合条件的培训计划去重数 |
| 指标 | 参训人数 | 符合条件计划内正式参训人员去重数 |

| 图表 | 机构合格率 TOP10 | 仅纳入有参训人员机构，按培训合格率降序 |

机构合格率 = 机构培训合格人数 / 机构参训人数。启用机构指标不得被日期、培训计划关键字或人员分类条件收窄，其余指标和明细使用本专题完整查询条件。

| 图表 | 老师授课时长 TOP10 | 按授课时长降序，课次、老师主键用于同值稳定排序 |
| 明细 | 一老师一行 | 老师、机构、专兼职、授课类型、计划数、课次、时长 |

专兼职、授课类型分别读取 `TeacherStaffCategoryEnum`、`TeachingTypeEnum`；同一老师存在多个授课类型时按老师和授课类型分行。

### 9.11 培训通过情况统计

| 类型 | 名称 | 口径或字段 |
| --- | --- | --- |
| 指标 | 参训人数 | 符合条件计划内正式参训人员去重数 |
| 指标 | 取得学时证明 | 已取得学时证明的参训人员去重数 |
| 指标 | 培训合格 | `training_qualify_status = '1'` 的参训人员数 |
| 指标 | 培训不合格 | 业务状态明确为不合格的参训人员数 |
| 指标 | 合格率 | 培训合格人数 / 参训人数 |
| 图表 | 合格率趋势 | 按计划开始月份展示培训合格率 |
| 图表 | 三类人员合格率 | 按 `QualificationRootCategoryEnum` 展示三类人员的培训合格率 |
| 明细 | 计划 + 机构 + 人员分类 | 计划名称、机构、人员分类、参训、学时证明、合格、合格率 |

同一人员跨计划时在各计划内分别统计；同一计划、机构、人员分类组合内按人员业务 ID 去重。

### 9.12 培训机构处罚统计

| 类型 | 名称 | 口径或字段 |
| --- | --- | --- |

| 指标 | 违规次数 | `tr_institution_evaluation.violation_count` 合计 |
| 指标 | 涉及违规机构 | `violation_count > 0` 的机构去重数 |
| 指标 | 不合格机构 | `EvaluationGradeEnum` 对应不合格等级的机构去重数 |

等级、状态分别读取 `EvaluationGradeEnum`、`EvaluationStatusEnum`。本专题仅使用地市、评估年度，不接受计划、人员分类、日期、单位或培训机构参数。

### 9.13 一键导出与归档资料

“一键导出六个”一次生成并下载一个 Excel，文件中只允许包含以下六个工作表，字段与对应专题明细一致：培训计划统计、培训人员统计、培训机构统计、授课老师统计、培训通过情况统计、培训机构处罚统计。每张工作表使用该专题最后一次成功查询条件；某专题尚无成功查询时使用该专题默认条件。导出失败整体提示，不拆分下载，不提供单专题导出。

“归档资料”为培训专题统计内的独立视图，拥有独立筛选、已归档培训班服务端分页列表和只读详情。进入详情仅展示归档时固化的培训班、计划、机构、人员、老师及结果信息；不提供归档包下载、编辑或删除操作。

## 11. 地图规范

- 地图只统计到地市，不单独展示信州区等区县。
- 地图和地市排名使用相同的地市上卷规则。
- 支持考试通过率、证书有效率两种模式，不提供待处理事项模式。
- 地市区域支持 hover 高亮并展示地市名称和当前指标值。
- 无数据地市仍保留轮廓并显示 `--`。
- 页面不展示高德地图 Logo、版权说明或相关字样。

## 12. 加载、空值与错误状态

| 状态 | 页面表现 |
| --- | --- |
| 加载中 | 当前分区显示系统加载状态，其他分区可继续使用 |
| 无指标值 | 指标卡显示 `--`；数量类真实零值显示 `0` |
| 无图表数据 | 面板显示系统“暂无数据”空状态 |
| 无表格数据 | 表格显示系统空状态 |
| 请求失败 | 仅失败分区显示错误信息和“重试”按钮 |
| 过期响应 | 前端丢弃，不覆盖最新查询结果 |

数据总览六区和培训专题六区均使用上述状态规则。培训专题额外记录每区最后一次成功查询条件，失败请求不得改写该条件；分页失败时保留当前成功结果和页码。
