# 考务人员端移动端 需求文档

- 版本：v0.1（原型基线）
- 日期：2026-09-30
- 关联文档：
  - 设计说明：`docs/superpowers/specs/2026-09-30-examiner-mobile-prototype-design.md`
  - 可点击原型：`index.html`（验收标准以原型实际行为为准）
- 状态说明：本文档只收录已确认并已在原型中实现的需求；未确认内容统一列入第 9 章"待定项"，不作为开发依据。

## 1. 背景与目标

### 1.1 背景

考务工作涉及考评员、监考员、巡考员三类现场人员。目前任务分派、响应、考生名单查看和履职情况查看缺少统一的移动端入口，需要一套考务人员共用的移动端应用。

### 1.2 目标

- 为三类考务人员提供统一移动端入口，当前登录人员只看到分派给自己的考务任务。
- 支持任务的查看、接受、拒绝（含原因）、考试开始前撤销接受（含原因）。
- 支持已接受任务的考生名单查看。
- 支持查看本人历史履职情况与分数统计。
- 本期为移动端原型基线，用于验证核心流程；不接真实接口、不接登录、不进入开考和评分流程。

### 1.3 非目标（本期明确不做）

- 不提供"开考""开始考试""评分操作"等任何开考与评分入口。
- 不提供"行为预警"页面。
- 不提供角色切换入口；角色由登录账号和权限决定。
- 不实现监考员、巡考员的专属任务内容与操作（仅纳入统一框架，待后续确认）。
- 不实现真实登录、鉴权、消息推送、离线缓存与数据持久化。

## 2. 角色与权限

| 角色 | 本期范围 |
| ---- | ---- |
| 考评员 | 完整功能：任务响应、撤销接受、考生名单、履职分析、个人中心 |
| 监考员 | 仅纳入统一框架，专属任务与操作待定 |
| 巡考员 | 仅纳入统一框架，专属任务与操作待定 |

- 角色由登录账号和权限决定，页面不提供角色切换入口。
- 当前登录人员只能看到分派给自己的考务任务。
- 原型默认以考评员账号演示。

## 3. 业务规则

### 3.1 任务状态机

任务状态共四种：

| 状态 | 标识 | 说明 |
| ---- | ---- | ---- |
| 待响应 | pending | 已分派，尚未接受或拒绝 |
| 已接受 | accepted | 已接受任务，解锁考生名单 |
| 已拒绝 | rejected | 已拒绝并记录原因 |
| 已完成 | completed | 历史任务，仅展示 |

状态流转：

```text
待响应 ──接受──> 已接受
待响应 ──拒绝（必选原因）──> 已拒绝
已接受 ──考试开始前撤销（必选原因）──> 待响应（保留"已接受后撤销"记录，可重新接受）
```

### 3.2 待办派生规则

- 待考试任务 = 状态为已接受，且当前时间早于该任务的具体考试开始时间（`startAt`）。
- 待处理考试 = 状态为待响应，不受考试日期影响，直到接受或拒绝。
- 考试开始时间已到的已接受任务：不再计入待办，但保留在任务中心历史中，且不能撤销接受。
- 已拒绝任务保留在任务中心历史中，不计入待办。

### 3.3 考生名单权限

- 仅"已接受"状态可查看考生名单。
- 待响应状态：不显示任何考生信息，只显示"接受后可查看考生名单"提示。
- 已拒绝状态：不能查看考生名单，显示锁定提示。
- 名单字段：姓名、脱敏证件号、考试科目、签到状态。

### 3.4 操作约束

- 接受任务：仅待响应状态可执行；接受后立即解锁考生名单，并记录操作。
- 拒绝任务：仅待响应状态可执行；必须选择原因（时间冲突 / 地点不便 / 临时有事 / 其他原因），未选择不能确认；拒绝后不能查看考生名单。
- 撤销接受：仅已接受且当前时间早于考试开始时间可执行；必须选择原因（临时有事 / 时间冲突 / 其他原因）；撤销后任务回到待响应，保留撤销记录与原因，允许重新接受。
- 考试开始后：隐藏"撤销接受"，仍可查看任务信息与已授权的考生名单。
- 所有操作（分派、接受、拒绝、撤销、完成）均保留操作记录，在任务详情中可见。

## 4. 功能需求

### 4.1 待办（首页）

- 顶部为分段式标签页："待考试任务"和"待处理考试"，默认进入"待考试任务"；两个标签页的数量角标直接显示在标签上，底部导航不再显示角标。
- "待考试任务"：展示状态为已接受且当前时间早于考试开始时间的任务卡片，卡片包含考试名称、具体考试日期、考试时间、考点、科目、当前状态。
- "待处理考试"：展示状态为待响应的任务卡片，字段同上。
- 两个标签页的卡片只用于提醒和进入详情，不接受、拒绝等操作不在卡片上直接进行。
- 卡片点击进入任务详情。
- 标签页为空时显示空态提示。

### 4.2 考务任务（任务中心）

- 顶部为状态筛选分段控件：全部 / 待响应 / 已接受 / 已拒绝 / 已完成，各选项展示对应数量；筛选控件为一行等分的分段控件，不换行不滚动；页面不再单独展示"考务任务"标题和描述文字。
- 列表展示当前人员被分派的全部任务，不因考试开始而丢弃历史记录。
- 点击任务进入任务详情。

### 4.3 任务详情

- 展示考试名称、任务状态、具体考试日期、考试时间、考点、考试科目。
- 已拒绝任务额外展示拒绝原因；曾撤销的任务展示上次撤销原因。
- 展示操作记录（分派 / 接受 / 拒绝 / 撤销 / 完成，含时间与原因）。
- 待响应状态：显示"接受任务""拒绝任务"两个操作，以及"接受后可查看考生名单"提示；不显示名单内容。
- 已接受状态：显示"查看考生名单"入口，显示名单人数；不再显示接受 / 拒绝操作；考试开始前显示"撤销接受"。
- 已拒绝 / 已完成状态：只读展示结果与历史记录。
- 任何状态都不出现开考入口、开考按钮或评分入口。

### 4.4 考生名单

- 仅已接受任务可打开。
- 以弹层 / 详情视图展示：姓名、脱敏证件号、考试科目、签到状态（已签到 / 未签到）。

### 4.5 分析

- 展示当前人员的历史履职与统计；本期默认展示考评员口径；页面不再单独展示"履职分析"标题和描述文字。
- 统计项：累计考评次数、本月考评次数、平均分、通过率、履职评分、最高分、最低分、合格人数、不合格人数。
- 月度考评趋势图（图表用轻量图形模拟，不接图表接口）。
- 历史考评记录列表：考试名称、考点、日期、考生人数、平均分、通过率；分析页展示最近三条预览。
- 点击"更多"进入全部历史考评记录列表页，支持按考试名称模糊搜索、按具体日期筛选、一键重置；展示符合条件的记录数量，无结果时显示空态提示；可返回分析页。
- 不展示"优秀 / 良好 / 待改进"等未经确认的分数段与等级标签。

### 4.6 我的

- 只展示：姓名、手机号、所属考点、累计考评次数、履职评分。
- 不增加身份证号、证书编号、擅长专业、通知设置、账号安全等未确认字段。

## 5. 非功能需求

- 形态：独立轻量单页，不安装依赖，不使用前端框架工程，不接真实接口。
- 技术：原生 HTML / CSS / JavaScript，内联 SVG 图标。
- 展示：电脑浏览器中以居中手机外框展示；手机尺寸（窄屏）下去掉外框占满全屏，内容可完整阅读和点击。
- 数据：本地模拟数据，仅保存在当前页面运行期间；刷新后恢复默认演示状态，不需要持久化。
- 演示时间固定为 `2026-09-30 14:00`，用于稳定复现"当天未开始 / 当天已开始 / 未来任务"等边界。
- 视觉：深蓝主色、暖黄重点色、浅灰蓝页面背景、白色卡片；状态色固定——待响应暖黄、已接受绿、已拒绝灰、已完成蓝；操作按钮大面积、易点击，重要动作用清晰文字，不依赖图标猜意思。

## 6. 数据需求（演示数据口径）

任务对象至少包含：任务 ID、考试名称、具体考试日期、考试开始时间、考试时间段文本、考点、科目、状态、考生名单、操作记录、拒绝原因、撤销原因。

演示数据至少覆盖：

- 一条待响应任务（演示接受与拒绝）。
- 一条已接受任务（演示已解锁的考生名单）。
- 一条当天尚未开始的已接受任务（演示待办展示与撤销接受）。
- 一条未来日期的已接受任务（演示待办中的近期任务）。
- 一条考试开始时间已到的已接受任务（演示待办过滤与撤销按钮隐藏，仍保留在任务中心）。
- 一条已完成任务（历史展示）。
- 一条已拒绝任务（展示拒绝原因）。
- 三条以上历史考评记录（分析页统计与趋势；记录总量多于预览条数，支撑"更多"列表与名称 / 日期查询演示）。
- 一组考生名单（姓名、脱敏证件号、考试科目、签到状态）。

## 7. 验收标准

- 打开原型即进入待办首页，四个底部入口（待办 / 任务 / 分析 / 我的）可切换。
- 待办首页包含"待考试任务"和"待处理考试"两个标签页，数量角标显示在标签上；待考试任务只含已接受且未到考试开始时间的任务；待处理考试只含待响应任务。
- 两个标签页的卡片都能进入任务详情；待处理任务在详情页接受或拒绝，已接受任务在详情页查看信息与名单。
- 未接受任务看不到考生名单，只看到解锁提示。
- 接受后名单入口解锁，待办统计同步变化（待处理减少、待考试增加）。
- 拒绝必须选择原因；确认后任务进入已拒绝，原因保留在任务中心与详情中。
- 考试开始前可撤销接受（必选原因）；撤销后任务回到待处理考试，保留"已接受后撤销"记录与原因，可重新接受。
- 考试开始后不显示"撤销接受"，仍可查看任务信息与已授权名单。
- 分析页展示第 4.5 节全部统计项与历史记录预览，无未确认分数段；点击"更多"可进入全部历史考评记录列表，并按名称、日期查询。
- 我的页面只展示已确认的五项信息。
- 全部页面与文案不出现"行为预警""开考""开始考试""评分操作"。
- 页面在手机尺寸下可完整阅读和点击，电脑预览保持居中手机外框。

## 8. 埋点与接口（预留，本期不实现）

真实项目阶段可拆分为以下接口方向（本期原型不提前实现）：

- 考务任务列表 / 详情接口
- 任务状态操作接口（接受 / 拒绝 / 撤销）
- 角色与权限接口
- 考生名单接口
- 履职分析接口

真实接入时，任务状态动作需替换为接口调用，并补充接口失败处理（原型只演示本地成功路径）。

## 9. 待定项（未确认，不作为开发依据）

- 监考员、巡考员的专属任务内容、操作规则与个人中心字段口径。
- 考评员分数的等级分段（如优秀 / 良好 / 待改进）是否采用。
- 监管端"考评员管理 → 详情"复用考评员分析内容的入口（本期不实现监管端）。
