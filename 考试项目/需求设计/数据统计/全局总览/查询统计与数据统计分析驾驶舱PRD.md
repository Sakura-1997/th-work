## 2. 背景与目标

数据总览用于集中展示培训、教师、考试、证书、考务人员和缴费等业务运行数据，辅助监管人员查看授权区域内的业务规模、通过率、人员结构、机构对比和趋势变化。V1.4 移除上一版新增的培训扩展视图、批量导出和培训班归档查询设计，在原数据总览中增加教师统计，重点回答“教师有多少、是否启用、专兼职结构如何、覆盖哪些考核项目”。

本版本以当前已经开发完成的数据总览页面为展示基线，PRD、HTML 原型、Vue 2 页面和 Vue 3 页面使用相同的模块、标题、字段与交互。页面仍使用 `/dataStatistics/overview/index`，不新增前端路由或左侧菜单。全部分区实时查询，不使用生产模拟数据、不缓存、不自动刷新。

## 5. 页面结构与视觉规范

页面采用现有监管系统的纵向驾驶舱布局，不设置页内一级视图切换。内容从上到下依次为：

1. 页面顶部公共筛选区。
2. 总览。
3. 培训分析。
4. 教师统计。
5. 考试分析。
6. 证书分析。
7. 考务人员。
8. 缴费分析。

视觉样式遵循现有系统：深蓝色左侧导航、`#1677ff` 主按钮和数据强调色、浅灰页面背景、白色面板、4px 左右的小圆角、细分隔线和紧凑型统计布局。分区标题左侧不显示 `01`、`02` 等序号。

## 6. 筛选与查询交互

### 6.1 数据总览筛选条件

| 筛选项 | 默认值 | 作用范围 |
| --- | --- | --- |
| 地市 | 全部授权地市 | 全部七个分区 |
| 开始日期 | 当前年度 1 月 1 日 | 除教师统计外的六个分区 |
| 结束日期 | 当前日期 | 除教师统计外的六个分区 |

时间范围使用一个开始日期和结束日期组成的日期范围选择器。开始日期不得晚于结束日期。

教师统计属于当前在册资源快照，只使用地市条件，不使用开始日期和结束日期。页面在教师统计标题旁明确提示“当前在册快照，不受时间范围影响”，避免用户误以为日期会改变教师存量。

### 6.2 查询行为

- 页面首次进入时，七个分区使用默认条件并行查询。
- 点击“查询”时，七个分区使用当前公共条件重新实时统计；教师统计仅取地市条件。
- 点击“重置”时恢复默认地市和本年度日期范围，并重新查询。
- 公共条件发生查询或重置时，培训机构明细、教师考核项目明细、考试安排明细和考务人员明细均回到第 1 页。
- 七个分区分别维护加载、错误和请求序号；一个分区失败不影响其他分区展示。
- 快速连续查询时，较早请求的迟到响应不得覆盖最新结果。

## 7. 公共数据口径

| 口径项 | 规则 |
| --- | --- |
| 删除标识 | 涉及业务表默认过滤 `del_flag = '0'`；没有该字段的表不添加此条件 |
| 监管范围 | 服务端根据当前用户授权区域强制收窄数据范围；地市用户不能通过参数扩大到其他地市 |
| 考试监管口径 | 考试统计按当前监管区域限制，不使用考试点机构 `tr_institution.tenant_id` 作为监管数据过滤条件 |
| 时间边界 | 开始日期包含当天；结束日期包含当天，SQL 使用结束日期次日零点作为排他上界 |
| 人数去重 | 人数优先按业务人员 ID 去重；跨考试实例统计人员时按身份证号等人员唯一标识去重 |
| 有效考试实例 | `instance_status = '1'`、`del_flag = '0'`，且 `exam_result IN ('1','2')` 或 `score IS NOT NULL` |
| 合格考试实例 | 有效考试实例中 `exam_result = '1'` |
| 培训合格 | `tr_trainee_signup.training_qualify_status = '1'`，其他值按业务状态分别计入不合格或待判定 |
| 启用机构数 | 仅受服务端授权区域和地市筛选影响，不受日期、培训计划关键字、人员分类影响 |
| 教师统计范围 | 复用教师管理服务的监管区域数据范围，默认过滤 `tr_teacher.del_flag = '0'`；不得仅按 `tenant_id` 猜测教师所属地市 |
| 启用教师 | `tr_teacher.teacher_status = 1`；`0` 为禁用，空值计入状态“未设置” |
| 教师人数去重 | 教师总量按 `tr_teacher.id` 去重；同一教师在同一考核项目下只计 1 人 |
| 教师考核项目 | `tr_teacher_qualification.qualification_id` 关联 `tr_qualification.id`；仅纳入两表 `del_flag = '0'` 的有效映射 |
| 区域上卷 | 服务端强制按授权区域收窄，区县数据上卷至所属地市；客户端参数不得扩大数据范围 |
| 机构监管过滤 | 监管统计不按 `tr_institution.tenant_id` 过滤 |
| 比率展示 | 后端返回 0 到 100 的百分数并保留 1 位；分母为 0 时返回 `null`，前端显示 `--` |
| 金额展示 | 当前支付链路金额单位为分，展示万元 = `SUM(amount) / 1,000,000`，保留 2 位 |
| 未归类数据 | 缺少人员分类时显示“未归类”；缺少地市的数据不参与地图着色和地市排名 |

## 8. 字典与分类规则

### 8.1 人员分类

人员分类名称由系统字典 `qualification_root_category` 或 `QualificationRootCategoryEnum` 提供，页面和服务端不得重复维护中文 Map。

| 编码 | 展示名称 |
| --- | --- |
| `01` | 主要负责人 |
| `02` | 安全生产管理人员 |
| `03` | 特种作业人员 |

考试报名和缴费优先从 `exm_exam_signup.exam_codes` 解析，无法获取时回退到 `exm_exam.exam_codes`；证书使用 `tr_certificate.person_type_code`。

### 8.2 考务人员类型

考务人员名称由系统字典 `staff_type` 或 `StaffTypeEnum` 提供。服务端兼容历史编码 `01/02/03` 与当前编码 `1/2/3`，统一映射为监考员、考评员、巡考员。

### 8.3 教师分类

教师专兼职和授课类型使用系统既有枚举，前后端均不得维护中文硬编码 Map：

| 业务字段 | 枚举 |
| --- | --- |
| 教师专兼职 | `TeacherStaffCategoryEnum` |
| 授课类型 | `TeachingTypeEnum` |

## 9. 指标来源与计算口径

### 9.1 总览

#### 核心指标

| 指标 | 来源 | 计算方式 |
| --- | --- | --- |
| 培训人数 | `tr_class_trainee`、`tr_class`、`tr_trainee_signup` | 查询期内正式入班人员数，按 `trainee_signup_id` 去重；`tr_class_trainee.status = 1` |
| 考试通过率 | `exm_exam_signup_instance`、`exm_exam_signup`、`exm_exam` | 合格考试实例数 / 有效参考考试实例数 |
| 首次通过率 | 同上 | 初考合格人员数 / 初考参考人员数；初考按 `exam_attempt_type = 0` 判断 |
| 证书有效率 | `tr_certificate` | 查询期内有效证书数 / 查询期内证书总数；有效证书需 `cert_status = '1'` 且当前日期位于证书有效期内 |
| 发证人数 | `tr_certificate` | 查询期内 `cert_status = '1'` 的证书按 `idcard_num` 去重 |

#### 图表与排名

| 组件 | 计算及展示规则 |
| --- | --- |
| 区域监管态势 | 以江西省 11 个地市为基线；支持“考试通过率”和“证书有效率”切换；区县区域上卷为所属地市；无指标值地市保留灰色轮廓并显示 `--` |
| 地市排名 | 当前地图模式对应指标的地市 TOP 5；只显示有有效指标值的地市，不单列区县 |
| 趋势对比 | 按月展示培训人数和考试通过率；查询范围内缺失月份由服务端补零或空值 |
| 机构通过率排行 | 按培训机构统计有效考试实例通过率：合格实例数 / 有效参考实例数，降序展示 TOP 4 |
| 人员分类分布 | 查询期内按报名人员去重，展示三类人员及未归类人员占比 |

### 9.2 培训分析

#### 核心指标

| 指标 | 计算方式 |
| --- | --- |
| 培训人数 | 查询期内正式入班人员数，按 `trainee_signup_id` 去重 |
| 参考人数 | 查询期内存在有效考试结果的人员数，按人员唯一标识去重 |
| 培训合格人数 | 查询期内 `tr_trainee_signup.training_qualify_status = '1'` 的正式入班人员数 |
| 机构考生通过率 | 查询期内全部机构合格考试实例数 / 有效参考考试实例数 |
| 启用培训机构 | 筛选区域内 `tr_institution.status = '0'`、`del_flag = '0'` 的全部启用机构数；不受日期范围影响 |

#### 图表与明细

| 组件 | 展示规则 |
| --- | --- |
| 培训人数趋势 | 按月统计培训人数；没有数据时显示“暂无数据” |
| 重点机构通过率 | 按有效考试实例通过率降序展示 TOP 4 |
| 培训机构考生考试通过率 | 服务端分页；列为培训机构、培训人数、参考人数、实例通过率、首次通过率、最终通过率 |

机构明细中的比率口径：

- 实例通过率 = 合格考试实例数 / 有效参考考试实例数。
- 首次通过率 = 初考合格人员数 / 初考参考人员数。
- 最终通过率 = 至少一次考试合格人员数 / 有考试结果人员数。

### 9.3 教师统计

教师统计放在“培训分析”之后、“考试分析”之前。原因是教师属于培训资源主数据，而考务人员是考试执行角色，两者数据来源、状态和统计目的不同，不应合并展示。

#### 核心指标

| 指标 | 计算方式 |
| --- | --- |
| 教师总数 | 授权区域内符合条件的教师按 `tr_teacher.id` 去重 |
| 启用教师 | 教师总数中 `teacher_status = 1` 的人数 |
| 专职教师 | 教师总数中 `staff_category` 对应专职的人数，不受启用状态限制 |
| 兼职教师 | 教师总数中 `staff_category` 对应兼职的人数，不受启用状态限制 |
| 覆盖考核项目 | 至少关联一名符合条件教师的 `tr_qualification.id` 去重数 |

#### 图表与明细

| 组件 | 展示规则 |
| --- | --- |
| 教师状态分布 | 环形图展示启用、禁用、未设置三类教师人数及占比 |
| 考核项目教师数量 TOP10 | 按项目教师去重数降序，启用教师数、项目编码用于同值稳定排序 |
| 考核项目教师统计 | 服务端分页；列为项目编码、考核项目、教师数、启用、禁用、专职、兼职、理论授课、实操授课 |

一个教师可以关联多个考核项目，因此会分别计入各项目；项目行的教师数不能直接相加作为教师总数。同一教师存在重复资格映射时，在同一项目内只计一次。未配置考核项目的教师只计入核心指标和状态分布，不进入项目 TOP10 与项目明细。考核项目名称读取 `tr_qualification.name`，项目编码读取 `tr_qualification.code`。

### 9.4 考试分析

| 组件 | 来源与展示规则 |
| --- | --- |
| 地市考试人数分布 | `exm_exam.examinee_number` 按考试点区域汇总；图表名称为“地市考试人数分布” |
| 考试类型与人员分类 | 同一横向条形图展示理论考试、实操考试及三类人员的考试人数 |
| 考试安排明细 | 服务端分页；列为考试日期、地市、考试点、考试类型、人员分类、考试人数；按考试日期和主键倒序 |

考试类型 `type = '1'` 展示“理论”，`type = '2'` 展示“实操”，其他值展示“未归类”。

### 9.5 证书分析

#### 核心指标

| 指标 | 计算方式 |
| --- | --- |
| 证书有效率 | 有效证书数 / 查询期内证书总数 |
| 发证人数 | 查询期内 `cert_status = '1'` 的持证人去重数 |
| 有效证书 | 查询期内 `cert_status = '1'` 且当前日期位于有效期内的证书数 |
| 持证人员 | 查询期内按 `idcard_num` 去重的持证人数 |

#### 图表与明细

| 组件 | 展示规则 |
| --- | --- |
| 证书状态 | 环形图展示“有效证书”和“其他证书”，副标题为“有效证书占比” |
| 证书办理量 | 按 `valid_begin_date` 统计，日期为空时使用 `create_time`，按月展示 |
| 持证人员分布 | 不分页；列为人员分类、持证人员、有效证书；不展示发证机关 |

### 9.6 考务人员

| 组件 | 展示规则 |
| --- | --- |
| 人员类别占比 | 仅统计 `status = '0'` 的启用人员，按监考员、考评员、巡考员展示环形图 |
| 人员数量概览 | 与人员类别占比使用同一启用人员数据，横向条形图展示人数 |
| 考务人员明细 | 服务端分页；列为区域、考试点、监考员、考评员、巡考员、数据状态；同一考试点的启用和停用数据按状态分行 |

数据状态在页面显示“正常”或“停用”，并使用系统现有标签样式区分。

### 9.7 缴费分析

#### 金额卡片

金额卡片按接口返回动态渲染，最多显示 6 张：

1. 缴费总额。
2. 缴费金额排名第 1 的地市。
3. 缴费金额排名第 2 的地市。
4. 特种作业人员缴费金额。
5. 安全生产管理人员缴费金额。
6. 主要负责人缴费金额。

接口未返回对应地市或人员分类时，不生成虚假的金额卡片。所有金额单位统一为万元，不展示金额占比。

#### 地市人员分类缴费情况

- 仅统计支付成功订单：`tr_pay_order.order_state = '1'` 或 `third_party_tran_status = '1'`。
- 金额优先取订单明细 `tr_pay_order_detail.amount`，没有明细时取订单 `tr_pay_order.amount`。
- 人员分类通过报名实例和报名信息解析，无法获取时回退到考试安排分类。
- 地市通过考试安排的考试点区域获取。
- 图表按地市展示三类人员金额的堆叠柱，柱顶为该地市缴费合计。
- 没有可归类的地市金额时显示“暂无数据”。

所有列表表头和字段统一居中。表格内容区保留左右内边距，分页区域位于右侧并保留右边距。列宽不足时允许表格内部横向滚动，不压缩或删除右侧字段。

## 11. 地图规范

- 地图只统计到地市，不单独展示信州区等区县。
- 地图和地市排名使用相同的地市上卷规则。
- 支持考试通过率、证书有效率两种模式，不提供待处理事项模式。
- 地市区域支持 hover 高亮并展示地市名称和当前指标值。
- 无数据地市仍保留轮廓并显示 `--`。
- 页面不展示高德地图 Logo、版权说明或相关字样。

## 12. 加载、空值与错误状态

| 状态 | 页面表现 |
| --- | --- |
| 加载中 | 当前分区显示系统加载状态，其他分区可继续使用 |
| 无指标值 | 指标卡显示 `--`；数量类真实零值显示 `0` |
| 无图表数据 | 面板显示系统“暂无数据”空状态 |
| 无表格数据 | 表格显示系统空状态 |
| 请求失败 | 仅失败分区显示错误信息和“重试”按钮 |
| 过期响应 | 前端丢弃，不覆盖最新查询结果 |

数据总览七个分区均使用上述状态规则。分页失败时保留当前成功结果和页码。

## 13. 接口对应关系

| 分区 | 接口 |
| --- | --- |
| 总览 | `GET /data-statistics/overview` |
| 培训分析 | `GET /data-statistics/training` |
| 教师统计 | `GET /data-statistics/teacher` |
| 考试分析 | `GET /data-statistics/exam` |
| 证书分析 | `GET /data-statistics/certificate` |
| 考务人员 | `GET /data-statistics/staff` |

数据总览公共参数为 `areaId`、`startDate`、`endDate`。教师统计接口只接收 `areaId`，项目明细分页时增加 `current`、`size`；前端不得向教师接口发送日期、单位、培训机构或 `rangeType`。其他分页接口增加 `current`、`size`。所有统计接口由服务端再次校验并收窄区域权限。

前端仍只有 `/dataStatistics/overview/index` 路由；教师统计作为原页面内分区，不注册新路由或新增左侧菜单。

## 14. 权限与数据范围

| 权限项 | 说明 |
| --- | --- |
| 区域权限 | 省级或超级管理员可查看全省；地市用户只能查看授权地市及其下属区域 |
| 参数收窄 | 用户选择地市时只能在已有监管范围内进一步收窄 |
| 金额权限 | 当前能访问数据总览的用户可查看缴费汇总金额，不增加页面二级权限标识 |
| 明细权限 | 当前能访问数据总览的用户可查看页面已有统计明细 |
| 教师统计权限 | 复用数据总览页面访问权限，只返回授权区域内聚合数据，不返回教师个人信息 |
