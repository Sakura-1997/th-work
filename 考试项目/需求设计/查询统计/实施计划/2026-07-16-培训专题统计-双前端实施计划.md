# 培训专题统计双前端实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Vue 2、Vue 3 现有数据总览中增加同路由页内培训专题组件，实现六专题独立查询、只读归档和六表导出。

**Architecture:** `overview/index.vue` 只维护一级页内视图和原数据总览；`TrainingTopicStatistics.vue` 维护六专题及内部“统计分析 / 归档资料”视图。纯函数 `trainingTopicPage.js` 统一默认条件、参数、请求序号、成功条件和导出载荷。图表、筛选、专题容器和归档详情拆为小组件，Vue 2 使用 Options API，Vue 3 使用 Composition API。

**Tech Stack:** Vue 2.7、Vue 3.5、Ant Design Vue、ECharts 6、现有 request/字典/区域组件、Node test、Playwright。

```javascript
export const TOPIC_KEYS = ['plan', 'person', 'institution', 'teacher', 'pass', 'penalty']

function formatLocalDate(date) {
  const month = `${date.getMonth() + 1}`.padStart(2, '0')
  const day = `${date.getDate()}`.padStart(2, '0')
  return `${date.getFullYear()}-${month}-${day}`
}

export function createTopicFilter(today = new Date()) {
  return {
    planKeyword: '',
    personType: undefined,
    areaId: undefined,
    dateRange: [`${today.getFullYear()}-01-01`, formatLocalDate(today)],
  }
}

export function createPenaltyFilter(today = new Date()) {
  return { areaId: undefined, assessmentYear: today.getFullYear() }
}

function cloneFilter(filter) {
  return JSON.parse(JSON.stringify(filter))
}

export function buildTopicParams(filter, page = {}) {
  return {
    planKeyword: filter.planKeyword || undefined,
    personType: filter.personType,
    areaId: filter.areaId,
    startDate: filter.dateRange?.[0],
    endDate: filter.dateRange?.[1],
    current: page.current || 1,
    size: page.size || 10,
  }
}

export function buildPenaltyParams(filter, page = {}) {
  return {
    areaId: filter.areaId,
    assessmentYear: filter.assessmentYear,
    current: page.current || 1,
    size: page.size || 10,
  }
}

export function createTopicState(filter) {
  return {
    draftFilters: cloneFilter(filter),
    committedFilters: cloneFilter(filter),
    current: 1, size: 10, loading: false, error: '', sequence: 0, data: {},
  }
}

export function buildExportPayload(states) {
  const withoutPage = (query) => {
    const result = { ...query }
    delete result.current
    delete result.size
    return result
  }
  const regular = (key) => withoutPage(buildTopicParams(states[key].committedFilters))
  return {
    planQuery: regular('plan'),
    personQuery: regular('person'),
    institutionQuery: regular('institution'),
    teacherQuery: regular('teacher'),
    passQuery: regular('pass'),
    penaltyQuery: withoutPage(buildPenaltyParams(states.penalty.committedFilters)),
  }
}
```
