## 2. 背景与目标

安全生产智慧培训考试模块需要对培训、报名、考试、制证、考务人员、缴费、评价投诉等全流程业务数据进行集中统计分析，支撑监管部门掌握辖区内业务运行情况、待处理事项、横向对比和趋势变化。

本模块以“驾驶舱统计类”风格呈现，优先服务监管决策和业务调度。系统需支持省、市、县不同层级按权限查看本辖区数据，并支持按区域、机构、考试点、考试类型、作业类别、操作项目、时间等维度查询、对比和下钻。

本期明确不统计考题相关数据，包括知识点、题型、题库、试题正确率、试题难度、错题排行、试卷质量等内容。考试相关统计仅覆盖报名、资格审批、到考、缺考、考试结果、违规记录、发证衔接等业务过程数据。

## 3. 产品目标

1. 建立全流程监管驾驶舱，展示培训、考试、证书、缴费、评价投诉等核心指标。
2. 建立查询统计专题，支持对培训管理、考试管理、证书管理、考务人员、缴费和反馈整改进行分主题统计。
3. 建立数据统计分析能力，支持同比、环比、排名、待处理事项汇总、关联分析和图表展示。
4. 支持按监管层级控制数据范围，满足省级看全省、市县看辖区的监管要求。
5. 支持指标明细下钻，便于形成监管台账和分析材料。

### 4.4 暂不设计指标

| 暂不设计项 | 原因 |
| --- | --- |
| 证书打印终端在线率、证书打印次数 | 当前表结构未看到明确的证书打印终端、打印记录字段 |
| 证书打印终端离线监测 | 当前表结构未看到证书打印终端在线状态字段 |
| 培训投入与成效投入产出分析 | `tr_training_plan.budget` 只有计划预算，未形成完整投入执行数据 |
| 机构密度与区域通过率相关性 | 可统计机构数和通过率，但“密度合理性”需要区域面积、人口或监管资源等外部数据 |
| 复杂考评打分偏差模型 | 当前可使用 `exam_perform_analysis` 做履职评分统计和低分人员排行，暂不设计复杂偏差模型 |
| 考题、题型、知识点、题库、试题质量分析 | 本期明确排除，且不作为查询统计模块指标 |

## 6. 信息架构

一级入口为“查询统计/数据统计分析”。页面采用顶部筛选、核心指标、专题分析、待处理事项的结构。

| 一级区域 | 二级内容 |
| --- | --- |
| 全局筛选 | 行政区域、时间范围、人员类型、作业类别、操作项目、考试类型、机构、考试点 |
| 核心驾驶舱 | 培训总人数、计划完成率、考试报考率、考试通过率、发证人数、证书有效率、缴费金额、待处理事项数 |
| 业务链路 | 报名、资格审批、培训完成、考试到考、考试合格、制证发证 |
| 专题分析 | 培训分析、考试分析、证书分析、考务人员、缴费分析、反馈整改 |
| 待处理事项 | 投诉举报待处理、作弊审核待审核、支付对账差异、证书推送失败 |
| 明细下钻 | 区域明细、机构明细、考试点明细、人员明细、待处理详情 |

## 9. 页面需求

### 9.1 监管驾驶舱总览

页面顶部提供全局筛选区。筛选条件变化后，核心指标、趋势图、排行榜、待处理事项列表同步刷新。

总览区展示 8 个核心指标：培训总人数、计划完成率、考试报考率、考试通过率、发证人数、证书有效率、缴费金额、待处理事项数。每个指标展示当前值、同比、环比、状态标识。

区域监管态势作为总览页中部主视觉展示，使用高德地图 JS API 作为底图，叠加江西地市行政区 GeoJSON 边界呈现各地市监管表现。地图采用 2D 俯视视角，默认按考试通过率着色，支持切换证书有效率、待处理事项数等指标。右侧同步展示地市排名和待处理事项构成，帮助领导第一眼判断重点区域和主要业务压力。

区域监管态势下方展示业务链路转化：报名人数、资格审批通过人数、培训完成人数、到考人数、合格人数、发证人数。每个节点支持点击下钻到对应明细。

左右两侧展示区域对比、机构排行、考试点排行和待处理事项。待处理事项只展示现有业务表中已有状态的数据，包括投诉举报待处理、作弊审核待审核、支付对账差异、证书推送失败等。

### 9.2 培训专题分析

培训专题展示培训计划、培训人员、培训机构、授课老师、培训完成率、学时完成率、培训通过情况和机构年度违规次数。

支持按培训机构、区域、时间、作业类别、操作项目进行查询。支持同比、环比分析，支持查看机构排行和低通过率机构清单。

### 9.3 考试专题分析

考试专题展示报名人数、资格审批、考试计划、应考人数、到考人数、缺考人数、合格人数、考试通过率、平均分、违规作弊次数。

不展示知识点、题型、题目、题库等考题相关统计。页面中不得出现“知识点考试统计”“题型统计”“试题分析”等入口。

### 9.4 证书专题分析

证书专题展示发证申请数、发证人数、持证人员数、有效证书数、即将到期证书数、证书有效率、证书推送成功率。

支持按发证机关、区域、时间、作业类别、操作项目、人员类型查询。

### 9.5 考务人员专题分析

考务人员专题展示监考员、考评员、巡考员数量和任务执行情况。支持按区域、考试点、任务时间、人员类型查询。

考务人员需支持履职低分人员统计。履职评分来自 `exam_perform_analysis`，页面展示综合结果，不在驾驶舱中扩展复杂偏差模型。

### 9.6 缴费专题分析

缴费专题展示缴费人数、缴费金额、缴费笔数、订单来源、支付渠道、退款金额、退款订单数和差异订单数。支付渠道无明确关联时，页面仅展示订单来源。

支持按部、省、市、考试点四级汇总，支持按日期趋势查看。

### 9.7 反馈整改专题分析

反馈整改专题展示评价总数、好评数、差评数、待处理评价数、已归档整改数、服务工单待处理数、服务工单已处理数和高频问题类型。

支持按时间、地区、评价对象、处理状态、作业类别、操作项目查询。

## 10. 交互规则

| 场景 | 规则 |
| --- | --- |
| 全局筛选 | 用户调整筛选条件后，页面所有指标按当前条件刷新 |
| 专题切换 | 点击专题页签后展示对应专题，保留全局筛选条件 |
| 指标下钻 | 点击核心指标可进入明细列表，明细列表继承当前筛选条件 |
| 区域下钻 | 省级可下钻到市，市级可下钻到县区，县级不可继续下钻 |
| 待处理事项查看 | 点击待处理事项进入对应明细，展示关联对象、业务状态和处置状态 |
| 刷新 | 支持手动刷新，驾驶舱默认按数据同步周期自动更新 |

## 11. 权限要求

| 权限项 | 说明 |
| --- | --- |
| 数据范围权限 | 按用户所属监管层级和行政区域限制可见数据 |
| 指标查看权限 | 可按角色控制是否查看缴费金额、投诉详情、人员身份信息等敏感指标 |
| 明细下钻权限 | 无明细权限时仅可查看汇总数据 |

## 12. 数据口径与刷新

| 项目 | 规则 |
| --- | --- |
| 人数去重 | 默认按身份证号或系统人员唯一标识去重 |
| 金额口径 | 以支付平台成功支付并完成对账的数据为准 |
| 证书口径 | 以证书状态和有效期为准，已注销证书不计入有效证书 |
| 反馈处置状态 | 评价反馈按待处理、待整改、整改中、已归档统计；服务工单按待处理、已处理统计 |
| 实时性 | 驾驶舱汇总数据建议 5 到 15 分钟刷新一次，明细查询可实时查询业务库 |
| 历史对比 | 同比为与去年同期对比，环比为与上一统计周期对比 |

## 13. 待处理事项统计口径

| 待处理事项 | 统计口径 | 数据来源 |
| --- | --- | --- |
| 投诉举报待处理 | `user_service_handle.status = 0`，或 `user_evaluation.status` 为待处理、待整改、整改中 | `user_service_handle`、`user_evaluation` |
| 作弊审核待审核 | `exam_candidate_cheat_record.review_status = PENDING_REVIEW` | `exam_candidate_cheat_record` |
| 支付对账差异待处理 | `tr_pay_reconcile_diff.handling_status` 不是已处理状态 | `tr_pay_reconcile_diff` |
| 证书推送失败 | `tr_certificate.push_status = 2` | `tr_certificate` |
| 证书即将到期 | `tr_certificate.valid_end_date` 距到期日小于等于 90 天 | `tr_certificate` |
