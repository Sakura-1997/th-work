# 图片生成

通过 TellHow Buddy 内置的 `pigwork_image_generate` 工具生成或编辑图片。模型、网关和厂商凭据由 TellHow Buddy 管理，不要要求用户提供 API Key，也不要直接调用厂商接口。

## 何时使用

- 文生图：根据文字描述生成新图片。
- 图生图：基于一张参考图修改主体、背景、风格、构图或尺寸。
- 多图融合：组合多张参考图中的主体、风格或布局信息，生成一张新图片。
- 交互编辑：根据画布里的编号注释、擦除范围和尺寸要求生成新版本。

仅理解图片内容而不生成新图片时，不调用本技能。

## 调用流程

1. 先判断任务是新图生成还是图片编辑。编辑必须保留原图并生成新版本。
2. 把用户意图整理成可执行提示词，写清主体与动作、构图、环境、风格或媒介、光线与色彩、限制条件和用途。保留用户的精确约束；除非用户要求，不要自行添加图片文字。
3. 为每张参考图声明唯一、明确的角色，例如“保持构图不变的基础图”“主体身份参考”或“仅参考配色风格”。引用只使用当前工作区图片路径，或工具先前返回的图片资产 ID。
4. 直接调用 `pigwork_image_generate`。用户已经明确要求生图或改图时无需再次确认；如果只是你认为配图可能有帮助，先询问用户。
5. 返回成功结果并说明可在“画布”继续标注、擦除或调整尺寸。用户需要长期保留时，提醒其保存到工作区或下载。

## 参数规则

- `prompt`：最终生成或编辑提示词，必须具体且完整。构图、比例、风格等要求用自然语言写进提示词。
- `references`：每项都要设置 `role`；使用 `workspacePath` 或 `assetId` 二选一。
- `parentAssetId`：继续编辑已生成图片时传入上一版本，用于形成非破坏性版本链。
- 不要传模型名称、尺寸、数量、水印等其他参数；模型选择和生成参数由 TellHow Buddy 服务端决定。

## 编辑约束

- 把当前画布图片作为基础图，并将编号注释、擦除框或尺寸要求写入提示词。
- 多轮编辑时继续引用上一版本，不覆盖来源图片。
- 对未标记区域，明确要求保持原有主体、构图、风格和光照不变。
- 首期不支持连续组图、流式生成、联网搜索、图层拆分和透明背景，不要声称已经提供这些能力。
