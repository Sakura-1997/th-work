问题定位与调整对策 problem → fix

维度现状问题调整对策
辨识度标题 130+ 字长句承担标题职责，"2026年9月24日+考点全称+考试类型+场次"全部堆在首行，两行折行后仍读不出重点；"上午场/第516批次"这类关键筛选维度被埋在句中。 标题重构为 「9月24日 · 周四」+ 时段徽章「上午场」，把用户真正用来挑场次的三个维度（日期/时段/考点）前置；考点从长句里拆出来独立成行，超出省略号截断。
辨识度名额 "剩余名额 0/200" 用 11.5px 浅灰置于右下角，紧贴费用且被按钮挤压，是全卡最弱的一处视觉，却是决定"能不能约"的唯一信息；"0/200" 缺少语义，需自行推断是"剩余"还是"已用"。 名额升为 决策色胶囊：余 12/200（绿）/ 余 8/200（橙，≤10% 时）/ 已满 0/200（灰）。颜色 + 文案双重编码，扫一眼即可分流。
误操作按钮 满额卡片仍给出与可约卡片完全相同的实心蓝主按钮"立即预约考试"，只有极淡的灰底做区分；用户按下去才发现约不了，是最大的误操作来源。列表底部 Tab 栏还挂了一个同文案的蓝色按钮，形成第二个误触点。 满额时不再渲染按钮，替换为无点击样式的说明行"本场已约满，暂不可预约"，从结构上消除误触；可约态文案收敛为 「预约考试」，与底部 Tab 栏 CTA 语义区分。
误操作状态反馈 整卡无状态标识，满额与否只能逐字读小字；点击后无中间态，重复点击容易产生重复预约。 卡片左侧 3px 状态竖条（蓝=可约 / 灰=已满）+ 名额胶囊共两处冗余编码；点击后按钮切换为"提交中…"并 1.5s 内禁用，避免重复提交。
简洁信息结构 5 行"标签：值"平铺，字段左边界随标签宽度浮动（"考试地址"4 字与"考点"2 字不对齐），视线需来回跳跃；"考试时间"重复书写两遍日期；"考试项目：特种作业人员"与页面标题完全重复。 时间归并为 08:00 – 12:00（日期已在标题）；删去重复的"考试项目"；三项元信息收进浅灰信息块，键固定 54px 宽左对齐，值统一起点，可纵向扫读。
简洁费用 "实操考试费：¥56.00" 与名额挤在同一行，两种无关信息互相争夺注意力，价格与名额都读不快。 费用独立成"标签 + 金额"两行块（¥56.00 用 17px 价格色），与右侧名额胶囊左右分立，底部形成清晰的 费用 — 名额 — 按钮 决策区。

设计规范 tokens & rules

圆角 / 阴影
16px
卡片 16px、信息块与按钮 12px；阴影两级 0 1 2 + 0 2 8，满额卡降一级。
内边距 / 间距
16 / 12
卡片内边距 16px，块间距 12px，卡片间距 12px，底部按钮上下留白 12/16px。
主按钮点击区
44px
按钮高度由 34px 提升到 ≥44px，满足可点击热区下限，降低误触与漏触。
名额阈值
10%
余量 ≤ 总名额 10% 转橙色"仅剩 N 位"，=0 转灰色已满；状态仅由数据驱动，不手工标注。
  • 字号与字重：日期 18/750 · 考点 13.5/600 · 元信息 12.5/400 · 名额 12/700 · 金额 17/750。全卡仅 3 级字重，避免"处处加粗等于没有重点"。
  • 色彩语义：蓝 #1677FF = 可操作/时间信息 · 橙 #FA6400 = 费用 · 绿 #00A870 = 余量充足 · 橙 #FF8F1F = 余量紧张 · 灰 #8C96A3 = 不可操作。同一颜色不在卡内承担两种语义。
  • 禁用态可读性：满额卡正文不再整体降透明度（会造成"这张卡坏了"的错觉），改用状态竖条 + 灰色名额胶囊 + 说明行表达不可用，考点、时间等决策信息保持正常对比度。
  • 触控隔离：卡片主体不可点击（仅按钮可点），避免"点卡片任意处即预约"；满额卡与相邻可约卡的按钮纵向间距 ≥16px，防止连击穿透。
  • 无障碍：名额胶囊与费用金额对比度 ≥4.5:1；状态不只靠颜色（附"已满/仅剩 N 位"文案）；时段徽章附带图标，"上午场/下午场"不依赖颜色区分。
  • 兜底文案：满额 → "本场已约满，暂不可预约"；未开放 → "9月20日 08:00 开放预约"；已约 → "已预约 · 查看凭证"。三种不可用原因分开表达，用户知道下一步该做什么。
